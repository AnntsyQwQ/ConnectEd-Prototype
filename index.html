📘 ConnectEd Player Manual

Read this before you start. It will help you play faster and avoid losing lives.

🎯 Goal

Complete network challenges, learn networking skills, earn points, and keep your lives.

🎮 How to Play

  • START CHALLENGE — guided path through all modules.
  • PRACTICE MODE — choose any module, no lives lost.
  • ALL MODULES — choose any topic, hearts deduct.
  • QUIZ — choose LO1–LO4, take that outcome's quiz.
  • DASHBOARD — see your progress and scores.

🕹️ Controls

Desktop: Drag and drop wires, devices, or items.

Mobile: Tap a wire, then tap a pin. Tap devices to connect them.

❤️ Lives & Score

You start with 5 lives. Wrong answers lose 1 life. Completing a challenge gives +100 points.

⏳ Cooldown

If you run out of lives, you must wait 3 minutes. During that time, only PRACTICE MODE is available.

💡 Tips

  • Read the micro-lesson before each challenge.
  • Use RESET if you get stuck.
  • Check the DASHBOARD for progress.
  • Adjust FONT SIZE in Settings if text is small.

📚 Modules Included

RJ45, Straight-Through, Crossover, Cable Tester, IP Config, CMD IP, Topology, Workgroup, Router, Security.
